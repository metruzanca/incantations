# Incantations Implementation Plan

Build `github.com/metruzanca/incantations` as a small Go CLI providing simple system-information utilities through shell functions.

## Architecture

Use **one `incantations` binary** with subcommands internally:

```text
incantations ram
incantations cpu
incantations disk
incantations gpu
```

Users should interact with the utilities directly:

```text
ram
cpu
disk
gpu
```

This is accomplished through shell functions generated by:

```bash
eval "$(incantations init bash)"
```

The `init` command must **only print shell code**. It must never modify `.bashrc`, `.zshrc`, Fish config, or any other user files.

## Project Structure

```text
incantations/
├── cmd/
│   └── incantations/
│       └── main.go
├── internal/
│   ├── ram/
│   ├── cpu/
│   ├── disk/
│   └── ...
├── go.mod
└── README.md
```

Keep each utility isolated and easy to add.

## Initial Commands

* `ram` - show total, used, and available memory plus top memory-consuming processes
* `cpu` - show CPU utilization and useful process information
* `disk` - show disk usage
* `init` - generate shell integration

Additional utilities should be easy to add without requiring users to modify their shell configuration.

## Shell Integration

Support Bash, Zsh, and Fish.

For example:

```bash
eval "$(incantations init bash)"
```

Generated Bash functions should look roughly like:

```bash
ram() {
    incantations ram "$@"
}

disk() {
    incantations disk "$@"
}
```

The generated functions should automatically reflect the utilities currently supported by Incantations. Adding a new utility should therefore require **no changes to the user's shell configuration**.

Keep generated shell integration deterministic and idempotent.

## UX Philosophy

The tools should be:

* Extremely simple
* Fast to launch
* Human-readable by default
* Opinionated rather than exposing dozens of flags
* Useful for answering common system-information questions without remembering complicated Unix pipelines
* Consistent with one another

The project concept:

> **Incantations — small system utilities for people who don't remember the incantation.**

## Implementation Priorities

1. Set up the Go project and CLI.
2. Implement `incantations init` with Bash, Zsh, and Fish support.
3. Implement `ram`.
4. Implement `disk`.
5. Implement `cpu`.
6. Add tests for command behavior and shell integration.
7. Document installation and shell setup in the README.

Avoid over-engineering. The goal is a collection of tiny, polished utilities with a consistent interface.
